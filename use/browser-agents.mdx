Some work has no API. It lives behind a login, in a dashboard, on a site that was never built for machines. Orbit workers handle it the way you would: in a **real browser**.

## What they can do

- **Open sites, click, fill forms, and read pages.**
- **Get past bot checks and captchas.**
- **Save downloads** and show screenshots right in the chat.
- **Use saved sign-ins**, kept inside their own workspace and nowhere else.

## Watch, and take over

The browser runs **live in the chat**. You see every step, and you can **take over at any moment**, type something yourself, hit **Paste** to drop in what you copied, then hand control back.

## Show the agent how

When a site is fiddly, you do not have to fight it every run. **Record the task once** in the browser and the agent follows the same steps from then on. The agent offers this on its own when the browser struggles.

- Saved steps show in the chat, and you can see and remove them.
- Pasted text is kept as typed steps. **Passwords are never read.**

<Note>
Only agents that Orbit runs have the browser. Browser time is billed. See [pricing](/help/pricing).
</Note>
