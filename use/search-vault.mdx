Your [Vault](/concepts/vault) holds everything your agents have filed. Search lets you — and your agents — pull any of it back on demand.

## From the dashboard

1. Open the **Vault**.
2. Type in the search bar. It matches meaning as well as keywords, so "Q3 revenue" also finds "third-quarter sales."
3. Filter by trust level, project, or agent to narrow results.
4. Click any result to read it in full.

## From an agent

This is where Orbit's shared brain shows up. In a brand-new session, ask:

> "Search Orbit for our latest positioning and use it to draft this."

The agent finds the filed work and builds on it — even though this session has never seen it before.

## Tip

**Search before you create.** Before asking an agent to research something, check whether a past agent already did. Reusing beats redoing.
