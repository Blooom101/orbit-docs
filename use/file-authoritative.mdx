Making something **authoritative** turns it into [Knowledge](/concepts/knowledge) — the highest [trust level](/concepts/trust-levels). Authoritative content is injected into every relevant agent's context at the start of each run, before it does anything else.

## Steps

1. Open the Vault item (or create new content).
2. Set its **trust level** to **authoritative**.
3. Orbit pauses and surfaces it in your Inbox for review — the **trust intercept**. Only you can ratify ground truth.
4. Review it (and any conflicts), then **approve**. From now on, every agent reads it as fact.

## Or just upload a document

You can also drop a file straight into your Brain, under **Personalization**, **Authoritative**, or **Other documents**. Each file becomes its own authoritative document, named after the file, and every agent gets it in its instructions on the next run (and can read the whole thing when it needs more).

Supported files: **PDF, Word, PowerPoint** (slides in order, with speaker notes), **Excel** (sheets by name), OpenDocument, RTF, web pages, and text files.

### The 5-page rule

An authoritative document holds **5 pages at most (about 2,500 words)**, so agents read the whole thing every run.

- A longer file, up to 30 pages, gets a **Summarize to 5 pages** option that keeps every price, name, number, and rule.
- Past 30 pages, it is too big to be authoritative. Long references belong in [Files](/concepts/vault) instead.

## What belongs here

- Confirmed pricing
- Positioning and messaging
- Brand voice rules
- Any rule that must never be contradicted

## Why the review gate exists

Authoritative content shapes every future run. The intercept lets an agent *propose* ground truth, but only you *ratify* it — so you stay in control of what your workforce treats as fact.
