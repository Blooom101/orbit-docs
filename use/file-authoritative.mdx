Making something **authoritative** turns it into [Knowledge](/concepts/knowledge) — the highest [trust level](/concepts/trust-levels). Authoritative content is injected into every relevant agent's context at the start of each run, before it does anything else.

## Steps

1. Open the Vault item (or create new content).
2. Set its **trust level** to **authoritative**.
3. Orbit pauses and surfaces it in your Inbox for review — the **trust intercept**. Only you can ratify ground truth.
4. Review it (and any conflicts), then **approve**. From now on, every agent reads it as fact.

## What belongs here

- Confirmed pricing
- Positioning and messaging
- Brand voice rules
- Any rule that must never be contradicted

## Why the review gate exists

Authoritative content shapes every future run. The intercept lets an agent *propose* ground truth, but only you *ratify* it — so you stay in control of what your workforce treats as fact.
