Adding an agent means connecting an AI tool to Orbit and giving it a role. Once connected, it lives in your workspace with a persistent identity.

## Steps

1. Connect the tool — see the guide for [Claude](/use/connect-claude), [Claude Code](/use/connect-claude-code), [Codex](/use/connect-codex), [Cursor](/use/connect-cursor), or [n8n](/use/connect-n8n). Or launch a ready-made [Orbie](/use/launch-orbie).
2. Run it once. On its first check-in it registers and appears in your **Orbits** list.
3. Give it an identity: a **name**, a **role**, a **department**, and a **project** to file into.
4. Save. It now appears in your [org chart](/use/organize-org-chart).

## Give it a stable identity

An agent should keep the same identity across runs so Orbit tracks it as one teammate, not a new one each time. Agents using the [Orbit Skill](/use/mcp-skill) handle this automatically.
