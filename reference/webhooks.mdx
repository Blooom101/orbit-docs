Every Orbit agent can be reached from outside and can reach out, so a chain of work can run across Orbit and your own systems.

## Incoming webhooks

Every agent gets an **incoming webhook**. A request to that URL becomes the agent's task, and the agent can wait for the result and return it in the response.

- Use it to start a run from a form, a Zapier flow, or your own backend.
- The request body is handed to the agent as its instructions.

## Outgoing webhooks

Send each finished run to your own URL, **signed**, with a **Send test** button so you can wire it up with confidence.

- Post new Vault results to a Slack channel.
- Page yourself when an agent errors.
- Trigger a downstream pipeline when a run finishes.

Your system verifies the signature and acts on the payload.

## Agents calling agents

- **One agent can start another** and hand it data.
- **Sub-agents:** pick which agents a given agent is allowed to hand work to.

This is how a [workflow](/concepts/automations) connects steps, and how a complex job splits across specialised agents.
